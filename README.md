# dsh-gugu-stock · 谷谷股

DSH 开着时每 15 分钟记录一次 DeepSeek 充值余额、WorkBuddy 积分、**日 Tokens 消耗**（可选：阿里云卡券余额），并在 **设置 → 谷谷股**（或左侧栏谷谷股图标）里出图。

## 快速开始 / Quick Start

面向第一次使用的用户，照下面五步做即可。

### 1. 准备 Python 与 matplotlib

出图由本机 Python + matplotlib 完成，需要 **Python 3.10 或更高版本**。先确认版本：

```bash
python --version
```

安装绘图依赖：

```bash
python -m pip install matplotlib
```

Windows 上如果 `python` 命令不可用，可用 Python 启动器（示例为 3.12，其他版本把 `3.12` 换成自己的版本号）：

```bash
py -3.12 -m pip install matplotlib
```

### 2. 安装插件

在 DeepSeek Harness 对话里让 agent 执行 `plugin_manager` 的 `install_bundle`，`target` 填**本仓库 `dsh-gugu-stock` 目录的绝对路径**（Windows 形如 `C:\...\dsh-gugu-stock`，不要填相对路径），例如对 agent 说：

> 用 `plugin_manager` 的 `install_bundle` 安装本地 bundle，target 是 `dsh-gugu-stock` 目录的绝对路径。

宿主代码更新后需要重启 DSH；Web 客户端部分由 HMR 自动生效。

### 3.（可选）安装出图 skill

想直接在会话里用「谷谷股」出图，把本仓库的 `skills/gugu-stock-charts/` 整个目录复制到 `~/.dsh/skills/` 下（Windows 即 `%USERPROFILE%\.dsh\skills\`），复制后即可在会话里使用。不装也不影响设置页里的按钮出图。

### 4. 30 秒验证

打开 **设置 → 谷谷股**：

1. 点「**立即采样**」，顶部数值卡出现读数即表示采样链路正常；
2. 依次点「**生成 · 余额折线图**」「**生成 · 花费柱状图**」「**生成 · 消耗累计图**」三个按钮，各自出图即表示 Python / matplotlib 环境就绪。

### 5. 隐私说明

所有采样数据只写在**本机**的单个 CSV 里，不会上传到本项目仓库；阿里云 AccessKey 等密钥**只写入本机、接口不回显**。详见文末免责声明。

- 数据文件：**只有一个 CSV** `%USERPROFILE%\.dsh\data\gugu-stock\balances-v2.csv`（`时间,来源,数值`，来源是 `ds` / `wb` / `al` / `ut`），所有数据都在这一个表里，**没有任何影子表 / 第二个数据源**。新采样**追加在文件末尾**（旧的在上、新的在下）；采样路径**只追加、不重写、不删除**任何已有行——从 Excel 粘贴的 Tab 分隔行、斜杠日期都照样读
- 阿里云卡券「使用流水表」可整表导入：`node acceptance/tools/import-coupon-flow.mjs`（读桌面的 `*-coupon_use_flow.csv`）。同一分钟多条按顺序分配秒 `:00/:01/:02…` 以全部保留，纯追加进同一个 CSV；导入后即进入 `al` 序列出图
- 两个入口：左侧栏图标（主视野大面板）+ **设置 → 谷谷股** 页签，共用同一套界面与数据
- 图表卡片下方「保存到桌面」：把当前这张图复制到桌面，文件名 `谷谷股_折线图_YYYYMMDDhhmmss.png` / `谷谷股_柱状图_YYYYMMDDhhmmss.png`（同名自动加 -2，绝不覆盖）
- 主界面只有三个按钮：**立即采样** / **生成 · 余额折线图** / **生成 · 花费柱状图**（Python + matplotlib）；其余设置都在一个**默认收起**的「配置」块里，展开状态刷新后保留
- 配置块三个板块：①打开文件（打开 csv 文件）；②数据源配置（三个开关：读取 DS 余额 / 读取 WB 积分 / 读取阿里云卡券，默认 开/开/**关**；阿里云需要填 RAM 子账号、卡券编号、AccessKey ID、AccessKey Secret，**默认全部为空**）；③缩放（DS 100% / WB 3.25% / 阿里云卡券 12.5%，`▲▼` 每次 ±0.25）+ 图表主题（明/暗/自动）+ **颜色来源（增减/数据源）**
- **第四个数据源 `ut` = 日 Tokens 消耗**（v1.19）：每 15 分钟把 **DSH 全部会话（含已归档会话）累计消耗的 tokens** 加总一次写进同一个 CSV 的 `ut` 行，**不需要任何手动输入**；面板上多一个「读取 Tokens 消耗」开关（默认开）、一个 `Tokens 消耗` 数值卡、以及它自己的缩放行（「多少 tokens 折 1 格」，默认 500 万）——因为 tokens 是消耗量而不是余额，缩放语义与另外三条不同。会话日志是多帧 zstd，按帧魔数逐帧解压后按 `(turn, step)` 去重累加，且有 `~/.dsh/data/gugu-stock/.token-cache.json` 按文件大小+mtime 缓存，全机 139 个会话首次 1.8 秒、之后 14 毫秒
- 顶部数值块（DS 余额 / WB 积分 / 阿里云卡券 / Tokens 消耗）按开关显隐、等宽排成一行；WB 卡片下面在**多个 WB 账号**时写「N 个账号合计」（采样值是各账号积分之和，v1.18.4 起）；生成的折线图与柱状图同样按开关增减线
- 所有设置落盘到 `settings.json`，刷新页面、重启插件都不丢；**阿里云 AK 只写进 DSH 凭据库 `~/.dsh/.credentials.yaml`，不进 `settings.json`、接口不回显**
- 折线图「谷谷股 · 余额折线图」：所选日期内每日最终余额（DS / WB / 阿里云卡券，各自按缩放百分比折算、标注显示原值）、横轴每月首日写 MM-DD 其余只写 DD、纵轴贴近 10 的倍数、网格线每 10 一条、相邻节点一律连线；图上数字取整且底衬是贴合字形的半透明描边；明/暗/自动主题
  - **Tokens 消耗线**永远是紫色（它表示消耗量，不适用涨红跌绿），并且 **每天 00:00 那个点从 0 起**、随后每个采样点画当天累计消耗，第二天再从 0 开始；只有每天最后一个采样点带数字，数字写成「6200万 / 1亿2千万」这种中文单位；**整条 ut 线铺满整个时间窗**——某天没有 ut 采样（或还没装 v1.19 的更早日期）就按 **0** 画，不是干脆不画
  - **颜色来源**在配置块里二选一：**增减**（默认）= 折线线段按涨跌着色（升红、降绿、平灰，DS 与阿里云都按此规则，WB 沿用主题浅红/浅绿/浅灰），图例是 DS 蓝 / WB 浅绿 / 阿里云橙红三个圆点；**数据源** = 三条折线各用固定色（DS 蓝、WB 绿、阿里云橙红），图例改成蓝/绿/橙红分别代表三个数据源。节点/数字颜色始终按数据源走，不受此选项影响
- 柱状图「谷谷股 · 花费柱状图」：每天花费 = 当天余额下降之和（充值不计、不抵消）、Tokens 那天消耗多少 tokens；各数据源柱子**一律等宽**并排（不再降低 WB 宽度）；**Tokens 柱固定紫色**、柱顶数字同样写「6200万」（没有数据的那天是 0 高柱子、柱顶写 `0`，同样铺满整个时间窗）；**增减**模式按涨跌着色（DS/阿里云花越多越红、越少越绿、中间黄，阿里云不再混浅色）并用**三种花纹区分来源**（DS 纯色无花纹 / WB 斜线 `///` / 阿里云圆点 `...`），**数据源**模式每根柱用数据源固定色（DS 蓝 / WB 绿 / 阿里云橙红）、不加花纹；图例是三根等宽小柱子（增减模式下带对应花纹）；柱顶数字按数据源取色（DS 蓝 / WB 绿 / 阿里云橙红）、纵轴 0 起、每 10 一条线、每天有分割线

## 阿里云卡券：怎么填（默认全空，全部由你自己填）

插件**不预填任何阿里云信息**，四个输入框默认都是空的。想让它开始记录卡券余额，按下面五步做一次即可：

1. **建一个只读子账号**：阿里云控制台 → 访问控制 RAM → 用户 → 创建用户，勾「使用永久 AccessKey 访问」、**不要**勾「控制台访问」。登录名会变成 `xxx@<账号ID>.onaliyun.com`，这就是要填的「RAM 子账号」。
2. **只给它一条只读权限**：在该用户的「权限管理」→「新增授权」→ 资源范围「账号级别」→ 策略类型「系统策略」→ 搜索框输入 `BSS` → 勾选 **`AliyunBSSReadOnlyAccess`** → 确定。**不要**勾 `AliyunBSSFullAccess`，也**不要**用 `PowerUserAccess` / `AdministratorAccess`（那是超级用户）。
3. **拿 AccessKey**：回到该用户 → 「AccessKey」→ 创建 AccessKey，记下 **AccessKey ID** 与 **AccessKey Secret**（Secret 只显示一次）。这个子账号除了查券什么都干不了，泄漏面很小；仍然建议只保存在本机。
4. **填进插件**：谷谷股 → 配置 → 数据源配置 → 打开「读取阿里云卡券」，填入 **RAM 子账号**、**卡券编号**（阿里云控制台「优惠券」/「卡券」列表里那张券的编号或 ID，纯数字即可）、**AccessKey ID**、**AccessKey Secret** → 点「测试阿里云」。看到券余额（形如 `269.03`）就成功了，顺手核对一下控制台上那张券的余额。
5. **等采样**：开关打开后，每 15 分钟一次的定时采样会多写一行来源为 `al` 的记录，折线图里多一条橙红色线，顶部多一个「阿里云卡券」数值块。

几点说明：

- 走的是官方 BSS OpenAPI：`https://business.aliyuncs.com/`，`Action=QueryCashCoupons`（`Version=2017-12-14`，HMAC-SHA1 签名），只读；返回的 `Balance` 就是该券剩余可用金额。
- 只覆盖**代金券**（CashCoupon）。储值卡、提货券是另外的接口（`QueryPrepaidCards`），本插件暂不支持。
- 接口返回两位小数（如 `269.03`），控制台有时显示更多位（如 `277.8555570325`）是内部精度，属正常。
- AK 存在 `%USERPROFILE%\.dsh\.credentials.yaml` 的 refs 段（名字 `ALIYUN_ACCESS_KEY_ID` / `ALIYUN_ACCESS_KEY_SECRET`），由 DSH 凭据服务管理；`settings.json` 里只有卡券编号与子账号，**没有密钥**，接口也只回 `hasAccessKeyId` 与掩码。
- 报错对照：`aliyun_credentials_missing` AK 没填/凭据库读不到；`aliyun_coupon_missing` 卡券编号没填；`aliyun_api_error` 且提示「没有 BSS 只读权限」= 子账号没挂 `AliyunBSSReadOnlyAccess`（或授权还要等 30~60 秒生效）；`aliyun_coupon_not_found` 卡券编号不对或不是代金券；`aliyun_network` 连不上阿里云；`aliyun_bad_payload` 返回内容异常。

## 在 DSH Go（手机）里用

中转连接下网页插件界面不可见，但插件注册了 Host 工具 `gugu_stock`，带 dsh-go 原生工具卡：

```
你：看看谷谷股        → gugu_stock（status）：DS 余额 + WB 积分 + 日终余额折线
你：立刻采样一次      → gugu_stock（sample）
你：生成谷谷股图      → gugu_stock（chart）：跑 Python 出余额折线图（工具卡固定默认 60 天）
```

改完 Host 代码要重启 DSH；细节见 `docs/DETAIL.md` 的「DSH Go」一节。

Skill 通道（`~/.dsh/skills/gugu-stock-charts`）**完全按面板当前设置出图**：主题、颜色来源、数据源开关、三条线缩放都从 `settings.json` 读，时间窗固定为面板默认的最近 60 天。不再接受 `--days` / `--from` / `--to` / `--theme` / `--wb-percent` / `--sources` / `--color-mode` / `--scale-*`（传了直接 `GUGU_FIXED_SETTINGS` 退出）。用 skill 出的图与面板点按钮出的图**逐字节相同**（`acceptance/tests/skill-parity.test.mjs` 比对 sha256）。想改图请先在设置页改。
- 面板上的数字按数据源上色（DS 蓝 / WB 绿 / 阿里云橙红 / Tokens 紫），大数字写成「7百万 / 4千万 / 1亿1千万」这种粗粒度中文单位。
- Tokens 在折线图上是**一片半透明紫色面积**（不画线和节点，只有每天最后一个点带数字），在柱状图上是**整天宽、半透明、垫在最后面**的紫色柱。
- 搬走一个 `balances-v2.csv` 就等于搬走全部数据（数据 + 面板设置都在表里），新机器用设置页的「导入 csv 文件」即可恢复成一样。
